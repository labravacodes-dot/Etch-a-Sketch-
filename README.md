# Etch-A-Sketch

An interactive browser-based drawing pad built as part of The Odin Project curriculum. This has no soul, no feeling. Unlike the rock paper scissors project, I cannot follow my vision in here while following the assignment at the same time. This just serves to fulfill the required assignment, and as base to do the real thing that feels right to me. Nonetheless, I thank the Odin Project for showing me the way to do this.

## Features
- **Dynamic Grid**: JavaScript-generated grid scalable up to 100x100.
- **Flexbox Layout**: Built strictly using CSS Flexbox.
- **Interactive Sketching**: Mouseover hover trail with progressive darkening shading.
- **Controls**: Canvas reset and clear functionality.

## Tech Stack
- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## How to Run
Open `index.html` in any web browser.
